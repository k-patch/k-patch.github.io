**Enshrouded** 의 기본 폰트를 다른 폰트로 변경 할 수 있는 모드입니다.
완벽하게 동작하는지는 알 수 없으나 폰트가 교체 되게끔만 되도록 제작된거라서 이상없이 된다는 보장은 없습니다.

일부 폰트는 충돌이 발생해서 시작 단계부터 게임이 종료되는데, 게임 자체에서 발생한 에러는 별도로 처리되는지 에러를 정확하게 파악이 안돼서 문제 파악이 어렵습니다.

그래서 만약 문제가 생긴다면 다른 폰트로 교체하길 권장드립니다.

TTF 폰트만 지원하고 크게 4가지 스타일로 구분되는데, 파일명에 따라 적절하게 폰트 스타일을 적용할 수 있습니다.\
자세한건 설치 방법을 참고하세요.

### 설치 방법

오른쪽에 파일선택을 눌러 2개의 파일 모두 받습니다.\
`dinput8.dll`가 이미 있다면 굳이 안받아도 됩니다.

1. `dinput8.dll`를 `인슈라오디드`가 설치된 폴더에 넣습니다.
2. 폰트 변경 모드(`font-changer.zip`)를 `인슈라오디드`가 설치된 폴더에 압축을 풉니다.
3. 모드의 `data` 폴더내에 `ko_kr` 폴더를 생성하고 원하는 폰트를 넣습니다.
4. 폰트는 아래 폰트 파일명 규칙에 따라 적절하게 폰트 스타일을 적용할 수 있습니다.

```
font-changer/
├── mod.json              
├── src/
│   ├── mod.lua           
│   ├── font_manager.lua  
│   ├── dynamic_font_indices.lua  
│   └── ttf_parser.lua    
├── data/                           # ← 여기에 언어별 폴더 생성
│   └── ko_kr/                      # 한국어 폰트
│       ├── NanumGothic.ttf         # 예: 나눔고딕 기본
│       └── NanumGothicBold.ttf     # 예: 나눔고딕 볼드
└── README.md
```

#### 폰트 파일명 규칙

`인슈라오디드`는 `Regular`, `Bold`, `Italic`, `Bold+Italic` 이렇게 4가지의 폰트 스타일을 사용합니다.

이에 맞춰 폰트 파일명에 아래처럼 스타일 키워드를 포함시켜 적용시킬 수 있습니다.

```
font-changer/
└── data/
    └── ko_kr/
        ├── NanumGothicRegular.ttf
        └── NanumGothicBold.ttf
```

만약 스타일 키워드를 넣지 않는다면 자동으로 굵기를 판단하여 Regular/Bold로 적용됩니다.

```
font-changer/
└── data/
    └── ko_kr/
        ├── NanumGothic.ttf         ← Regular 자동 감지!
        └── NanumGothicB.ttf        ← Bold 자동 감지!
```

기울임(italic)은 통상 자동으로 처리되나 인슈라오디드는 폰트를 직접 지정해야 되는거 같습니다...\
그래서 보통 위 예제들 처럼 적용을 안할경우 기본 폰트로 적용되므로 적절하게 폰트를 구해서 넣던가 아니면 직접 만들어서 넣던가 해야 될겁니다.

#### 🔧 문제 해결

##### "No fonts found to apply" 경고가 뜨는 경우

* `data/` 폴더 안에 언어 코드 폴더를 만들었는지 확인
* 해당 폴더 안에 `.ttf` 파일이 있는지 확인
* 폴더명이 게임 언어 코드와 일치하는지 확인 (언더스코어 포함, 대소문자 무관)

  * 올바른: `Ko_Kr`, `ko_kr`, `KO_KR`, `En_Us`, `en_us`
  * 잘못된: `korean`, `Ko-Kr`, `KoKr`

##### "Language code not found in any language group" 경고가 뜨는 경우

* 폴더명이 게임에서 실제로 사용하는 언어 코드와 일치하지 않습니다
* 로그에서 `Looking for language code: [코드]` 메시지를 확인
* 올바른 언어 코드 형식 예시: `Ko_Kr`, `Ja_Jp`, `En_Us`

##### "Font file not found" 경고가 뜨는 경우

* 언어 폴더 안에 `.ttf` 파일이 있는지 확인
* 경로 예시: `data/Ko_Kr/NanumGothic.ttf` (O), `data/NanumGothic.ttf` (X)

##### 게임에서 폰트가 바뀌지 않는 경우

* 모드가 활성화되어 있는지 확인
* 로그에 "Successfully replaced" 메시지가 있는지 확인
* 폰트 파일이 유효한 TTF 형식인지 확인
* 올바른 언어 폴더에 파일을 넣었는지 확인

##### 게임이 크래시되거나 글자가 깨지는 경우

* 폰트가 해당 언어를 지원하는지 확인 (한글 폰트에 한글 글리프 포함 여부)
* 파일 크기가 너무 크지 않은지 확인 (20MB 이하 권장)
* 다른 폰트로 시도해보기
